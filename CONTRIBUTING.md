# Contribuyendo a rqtll-docs

¡Gracias por ayudar a documentar RQTLL!

## Flujo de Trabajo para Documentación y Capturas

1. **Estructura del Proyecto**: Asegúrate de colocar cada captura en la carpeta correcta:
   - Capturas vectoriales puras en `screenshot/<theme>/svg/`.
   - Capturas ligeras para la web en `screenshot/<theme>/web/` en formato `.webp`.
   - Exportaciones PDF en `screenshot/<theme>/pdf/`.
2. **Pull Requests**: Describe qué pantalla o módulo estás documentando o actualizando y enlaza las capturas añadidas.
